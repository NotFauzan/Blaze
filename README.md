This is a demo website I built for an inter-school competition to highlight my frontend web development skills.

### ⚠️ Important Notice

This project is **not a real, working web application**.

- It does **NOT** accept orders  
- It does **NOT** process payments  
- It does **NOT** include a backend  
- There is **no payment gateway** integrated  
- No user data is stored or collected

All buttons, forms and interactive elements are for **UI/UX demonstration only**.
